## Challenge: Profile Card (React Fundamentals)

### Overview
A hands-on exercise focused on applying the foundational concepts of React, including component composition, JSX, props, conditional rendering, and list rendering.

### Key Concepts Practiced
- **Components & Composition**: Breaking down the UI into modular, reusable components.
- **JSX & Styling**: Writing declarative markup and applying styles via CSS classes and inline styles.
- **Props & Destructuring**: Passing data cleanly between parent and child components.
- **Rendering Lists**: Dynamically rendering skill tags and data using JavaScript's `.map()` method.
- **Conditional Rendering**: Applying conditional styling or rendering elements based on props and logic.
