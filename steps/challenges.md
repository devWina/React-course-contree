This document outlines the coding challenges designed to practice and solidify state management concepts in React.

## Challenge 1: Date Counter

### Overview
A hands-on exercise focused on understanding and managing component state in React by building an interactive date counter application.

### Key Concepts Practiced
- **State Management**: Using the `useState` hook to manage dynamic counters and steps.
- **Event Handling**: Updating state in response to button clicks and user interactions.
- **Dynamic Date Calculations**: Calculating and formatting dates dynamically relative to today's date based on state values.
